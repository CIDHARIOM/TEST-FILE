# ANDOS Next

A premium, trust-first, mobile-first redesign of the ANDOS digital services experience.

## Run locally

```bash
npm install
npm run dev
```

Production validation:

```bash
npm run lint
npm run build
npm run preview
```

## What is included

- Guided home experience
- Intent-oriented search
- Service catalogue and service-detail views
- Plan decision-support architecture
- Four-step checkout preview
- Order tracking center
- Wallet and payment architecture
- Rewards 2.0 and achievements
- My ANDOS dashboard
- Trust Center
- Security & Privacy Center
- Events Hub
- Community
- ANDOS Academy
- ANDOS Inbox
- Support
- System Status
- Desktop sidebar, responsive layouts, Android-style bottom navigation and sheets
- Keyboard focus, reduced-motion, and safe-area support

The baseline repository did not include an existing app or live data contracts. For that reason, the UI marks disconnected data and does not invent prices, balances, reviews, status, events, or user activity. See [`PRODUCT_AUDIT.md`](./PRODUCT_AUDIT.md) for the complete audit and integration map.

## Stack

- React 18
- Vite 6
- Lucide React
- Manrope Variable + Inter Variable
- Tokenized CSS design system
